# Контроль поручений 📋

Модуль КПН-Агента: реестр и мониторинг исполнения поручений.

## Как работает

1. Поручения извлекаются из стенограмм/протоколов совещаний
2. Каждое получает номер (КПН-001), ответственного, срок
3. Бот пинает ответственных в Telegram
4. Дайджест закрепляется в топике КПН

## Формат поручения

| Поле | Пример |
|------|--------|
| Номер | КПН-001 |
| Формулировка | «Подготовить отчёт по...» |
| Ответственный | ФИО |
| Срок | дата |

## Интеграции

- **Telegram** — уведомления, дайджесты (лимит ~4096 символов → DOC для больших)
- **YouGile** (перспектива) — выгрузка как задач
- **PostgreSQL/SQL** — дедупликация при поступлении

## Известные проблемы

- Рабочие группы не отображаются в дайджесте
- Порядок сообщений — нужна сортировка
- Несколько фамилий → уточнение у секретаря
