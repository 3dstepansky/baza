Мультиагентная система code review для «Синергии»

Идея

Создать для «Синергии» систему ревью кода, в которой несколько специализированных агентов независимо проверяют изменения, а общий оркестратор объединяет замечания в единый проверяемый результат.

Предварительная ролевая схема

  • Оркестратор — получает diff или pull request, распределяет проверки и сводит результаты.
  • Reviewer корректности — ищет логические ошибки, регрессии и несоответствие требованиям.
  • Security reviewer — проверяет секреты, права, уязвимости и опасные операции.
  • Architecture reviewer — оценивает границы модулей, зависимости и технический долг.
  • Test reviewer — проверяет покрытие сценариев и предлагает недостающие тесты.
  • Style/maintainability reviewer — оценивает читаемость, дублирование и сопровождаемость.
  • Арбитр — устраняет дубли, ранжирует замечания по критичности и отделяет подтверждённые дефекты от предположений.

Принцип синергии

Ценность возникает не из количества агентов, а из разделения ответственности, независимой проверки и общего quality gate. Каждое замечание должно содержать место в коде, объяснение риска, уровень критичности и практичное исправление. Финальный вывод не должен повторять одинаковые замечания разных агентов.

Минимальный результат ревью

  1. Краткий вердикт по изменению.
  2. Блокирующие дефекты.
  3. Замечания по безопасности и архитектуре.
  4. Недостающие тесты.
  5. Неблокирующие улучшения.
  6. Ссылки на конкретные строки или файлы.
  7. Уровень уверенности и фактические проверки.
