AI Freebies 🧻

Пакет бесплатных полезностей под ИИ-веселья — максимально разная хуйня, от скинов на клиенты до скиллов для автоматизации телеги.

🩲 Кастомизация Codex Desktop

Тюнинг Codex под свои представления. Визуальные дрочеры могут: - Ставить хентай на фон кодекса - Прописывать кастомные CSS - Сейвить theme и ставить на апку

«Я себе сфотожабил пуджа на фоне поля из обоев винды xp»

🩲 ИИ агрегатор для ресерча

Агрегатор на базе топ моделей (Opus 5 есть). Даёт 10 запросов в день бесплатно.

«Я по фану попросил собрать стату по всем убийствам с 2000-го года в районе в котором я вырос и чел на opus 5 полез в мусорские базы рыть эту темку»

🩲 Score API провайдера

Рейтинг API провайдеров — забавно когда китайцы рейтят китайцов. Но может быть полезно.

🩲 Интерактивный разбор кода

Сайт даёт промпт для интерактивного разбора вашего кода. Полезно чтобы: - Углубиться в код - Проверить зависимости - Посмотреть строение кода на мапе для образования - Работает почти со всеми моделями

🩲 MCP для Telegram ⭐

Охуенная тема. MCP-сервер, который подрубает телеграмм к нейронке.

Возможности: - Полноценная новая сессия в телегу, управляемая через терминал - Рассылки - Запланированные сообщения/посты - Поиск по чатам без чтения (когда чатов дохуя) - Особенно удобно для админов и воркеров по ТГ

См. также: MCP Протокол

🩲 Продвинутая панель для Claude CLI

Кастомная панель для Claude CLI: - Показывает больше информации - Расход контекста - Прайс токенов - Количество изменений - 11 встроенных тем на клиент

🩲 Библиотека скиллов для Claude Code

Репозиторий с: - Скиллами - Саб-агентами - Командами - Плагинами для Claude Code

В репозитории шерстишь файлы и берёшь то что нужно — не надо целиком ничего ставить.

🧠 Топовые модели по API за лоупрайс

Чат-канал с топовыми моделями по API за низкую цену.
