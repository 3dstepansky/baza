# Wiki-ссылки в Obsidian 🔗

Синтаксис внутренних ссылок между заметками vault.

## Основной синтаксис

| Синтаксис | Результат |
|-----------|-----------|
| `[[Заметка]]` | Ссылка по имени |
| `[[Заметка\|Текст]]` | Ссылка с текстом |
| `[[Папка/Заметка]]` | Ссылка по пути |
| `[[Заметка#Заголовок]]` | Ссылка на раздел |
| `[[Заметка#^block]]` | Ссылка на блок |

## Особенности этой базы

- Формат ссылок: `[[Путь/Имя|Отображаемый текст]]` — короткий и явный
- Хабы ссылаются на все дочерние заметки
- Каждая заметка должна иметь **обратные ссылки** (не быть сиротой)

## Зачем

- [[concepts/llm-wiki|LLM Wiki]] строится на перелинковке
- Граф связей генерируется из wiki-ссылок
- Навигация в Obsidian и на опубликованном сайте
