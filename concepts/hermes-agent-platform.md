# Hermes Agent — Платформа для КПН

**Hermes Agent** — мульти-агентная платформа с Kanban-оркестратором.

## Ключевые возможности (для проекта)

### Мульти-агентность
- Один агент Gateway слушает Telegram
- Оркестратор роутит задачи специализированным агентам
- Каждый агент имеет свой профиль и набор скиллов
- Маштабируется до 15+ агентов

### Kanban-оркестратор
- Gateway → Kanban Board → Оркестратор → Агенты
- Позволяет трекать состояние каждой задачи
- Комментарии к задачам для меж-агентской коммуникации

### Telegram-интеграция
- Поддержка топиков Telegram
- Gateway-агент слушает и пишет в чаты
- Поддержка закреплённых сообщений, тредов

### LLM-гибкость
- Смена модели на уровне агента: Ollama (локально) или Claude/OpenAI (внешние API)
- Per-agent model override

## Инфраструктура
- **Дев-сервер** (Павел) — инновации, тесты
- **Прод-сервер** (Медведев) — стабильная версия
- `~/.hermes/` конфигурация копируется для полного клона
- Релизный пайплайн после отладки

## Примечания
- Hermes нужно настроить на русский язык ответов, убрать тех. мусор
- Агенты общаются на русском, пишут сводки в топик КПН
- Kanban-доска как единое окно состояния
