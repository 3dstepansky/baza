# Go 🦫

Системный язык для высоконагруженных сервисов, сетевых инструментов и CLI.

## Когда использовать

- Высоконагруженные сетевые сервисы и прокси
- CLI-утилиты с одним бинарником
- Инструменты, где важна скорость и низкое потребление памяти
- В отличие от Python — нет GIL, лёгкая конкурентность через goroutines

## Ключевые особенности

- **goroutines** — дешёвая конкурентность
- **Статическая типизация** — безопасность на этапе компиляции
- **Один бинарник** — простой деплой (Docker scratch)
- Встроенный HTTP-сервер в stdlib
