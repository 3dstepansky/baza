# LLM Wiki — концепция и архитектура 🧠

Karpathy-style персональная база знаний: плоские атомарные заметки, сильно перелинкованные Wiki-ссылками. Хранится в Obsidian vault.

## Принципы

- **Атомарность** — одна заметка = одна идея
- **Перелинковка** — каждая заметка ссылается на смежные (минимум текста, максимум ссылок)
- **Хабы** — `index.md` в каждом разделе для навигации
- **Рост органический** — заметки добавляются по мере появления знаний

## Структура vault

```
baza/
├── Dev/          — разработка
├── AI-ML/        — модели, MCP, исследования
├── Trading/      — алготрейдинг
├── System/       — серверы, Hermes
├── Concepts/     — Karpathy-style концепции
├── Projects/     — активные проекты
└── Synergy/      — холдинг «Синергия»
```
