# job_search 🎯

Универсальный инструмент для поиска работы, который позволяет эффективно собирать вакансии с различных сайтов с помощью командной строки.

**GitHub:** [jozefRudy/job_search](https://github.com/jozefRudy/job_search)
**Стек:** Rust, SQLite, Lance (векторные эмбеддинги), SolidJS, Chromium/CDP
**Лицензия:** MIT

## Ключевые функции ⭐

- CLI-интерфейс с единой точкой входа
- Поддержка площадок: **Upwork**, **LinkedIn**, **NoFluffJobs**, **eFinancialCareers**, **Hacker News**
- Локальная SQLite-база + векторный поиск (nomic-embed-text-v1.5)
- Web UI (SolidJS, встроен в бинарник)
- Конфигурация через TOML-файл (настройка через URL, не через CLI-аргументы)
- Инкрементальный embed (только новые вакансии)
- Диагностика: размер БД, моделей, датасетов

## Настройка 💡

Конфигурация через `jobsearch.toml`:
- `location`, `pause_ms`, `[browser]` (путь к браузеру)
- URL площадок с параметрами фильтрации прямо в URL
- Браузер должен быть запущен с залогиненными аккаунтами

## Ограничения ❌

Не подходит для сайтов, которые ограничивают доступ к данным или имеют жёсткие правила по сбору информации.

## Заметки

- Инструмент запомнен по рекомендации из Telegram (30.07.2026) — может пригодиться для проекта по поиску работы
- Использует настоящий браузер (Chrome/Brave) через CDP — требуется живая сессия
- Emebddings работают локально, без API-ключа
