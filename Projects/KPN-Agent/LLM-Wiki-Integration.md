# LLM Wiki — интеграция в КПН-Агент 🔄

Подключение базы знаний к системе контроля поручений.

## Что даёт

- Бот складывает протоколы, регламенты, поручения, термины в vault
- Вопросы на естественном языке → ответы из базы знаний
- Обогащение wiki на основе расшифровок совещаний
- Связь поручений с контекстом (кто, что, когда)

## Архитектура

```
Стенограммы/протоколы → Hermes Agent → Obsidian vault (LLM Wiki)
                                    ↓
                      Ответы на вопросы (RAG/GraphRAG)
```
