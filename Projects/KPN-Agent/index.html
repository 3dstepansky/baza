Проект КПН-Агент

Автоматизация контроля поручений (КПН) на базе Hermes Agent и LLM Wiki.

Цель

Построить систему, которая: 1. Автоматически извлекает поручения из протоколов/стенограмм совещаний 2. Создаёт и ведёт реестр поручений 3. Интегрируется с YouGile для отслеживания статусов 4. Уведомляет ответственных через Telegram 5. Предоставляет дайджесты и контроль исполнения 6. Обогащает Wiki-базу знаний на основе расшифровок

Текущий статус

См. Контроль поручений
