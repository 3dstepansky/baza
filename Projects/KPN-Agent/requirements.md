# Контроль поручений — Функциональные требования

## Основные функции бота

### 1. Пинание ответственных
- Бот отмечает ответственного: «У тебя поручение, что делаем?»
- Механика: ответственный пишет «по мне всё ОК» — бот отмечает

### 2. Дайджест
- Закреплённое сообщение в топике КПН
- Содержит: поручения, ответственные, сроки, статус (активно/срочно)
- Ограничение Telegram: ~4096 символов → для больших таблиц DOC-файлы

### 3. Бизнес-ассистент
- Держит всю картину в голове
- Предупреждает о событиях («в понедельник у нас 4 поручения»)
- Связь поручений с докладами

### 4. Дедупликация
- Проверка PostgreSQL/SQL при поступлении протокола
- Если уже есть — не дублировать

## Формат поручений
- Номер: КПН-001 (постоянный)
- Формулировка из стенограммы
- Ответственный (ФИО)
- Срок

## Связь с YouGile (перспектива)
- Олег выдвинул идею обогащения контекста через YouGile
- После совещания → выгрузка в YouGile
- Требуется проверка актуальности

## Проблемы (из встреч)
- Рабочие группы не отображаются в дайджесте
- Порядок сообщений — нужна сортировка
- Если несколько фамилий — писать секретарю на уточнение
- Чаты: не всем, только по делу
