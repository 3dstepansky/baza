# Baza — LLM Wiki 🧠

Персональная база знаний на базе Obsidian, управляемая через Hermes Agent.

## Структура

```
baza/
├── Dev/          — разработка, тулы, языки
├── AI-ML/        — модели, MCP, free-tier, исследования
├── Trading/      — алготрейдинг, стратегии
├── System/       — серверы, сеть, Hermes
├── Concepts/     — Karpathy-style LLM Wiki
├── Projects/     — активные проекты
├── Synergy/      — холдинг «Синергия»
└── index.md      — корневой хаб
```

## LLM Wiki

Заметки создаются через MCP-инструменты Hermes Agent.
Каждая заметка — markdown, сильно перелинкованный Wiki-ссылками.
