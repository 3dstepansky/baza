Student Appeals Agent — агент контроля обращений студентов

Суть

Student Appeals Agent — проект агента для контроля обращений студентов в приемной комиссии. Агент должен подключаться к почтовым ящикам сотрудников, отслеживать входящие обращения, контролировать сроки обработки и отправлять уведомления/отчеты через Telegram. ^[raw/transcripts/telemost-2026-08-10-student-appeals-agent-summary.md]

Принятые решения

Решение Значение для проекта
Подключаться к почтовым ящикам сотрудников Нужен технический доступ к ящикам или сервисная учетная запись
Использовать Telegram Канал уведомлений, напоминаний и отчетов
