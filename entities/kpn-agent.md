# Проект КПН — Контроль поручений

**Цель:** Автоматизация контроля исполнения поручений на базе Hermes Agent + LLM Wiki.

## Контекст
Проект родился из потребности холдинга «Синергия» (1 910 подразделений, 5 894 сотрудника) автоматизировать контроль поручений, которые выдаются на еженедельных КПН (контроль поручений начальника).

## Ключевые компоненты

### 1. Реестр поручений
Единое хранилище поручений, извлекаемых из стенограмм КПН. Каждое поручение имеет номер (КПН-001), ФИО ответственного, срок.

### 2. Входные данные
- Стенограммы от Милены (с совещаний)
- Протоколы от Елены
- Ручные пересылки документов в чат

### 3. LLM Wiki (Obsidian vault)
Человекочитаемое хранилище знаний. Бот складывает протоколы, регламенты, поручения, термины. Доступ через вопросы на естественном языке.

### 4. Telegram-бот
- **Закреплённое сообщение** в топике КПН (дайджест: поручения, ответственные, сроки)
- **Личные сообщения** — пинает ответственных
- **Дайджест** 1 раз в день
- **DOC-документы** для больших таблиц (если >4096 символов)

### 5. YouGile интеграция (перспектива)
Выгрузка поручений из реестра в YouGile как задачи.

## Архитектура (Kanban-оркестратор)

```
1. Gateway — слушает Telegram → кладёт события в Kanban
2. Оркестратор — роутит по типу (протокол, таблица, вопрос)
3. Специализированные агенты (~15 шт):
   - Агент регламентов КПН
   - Агент терминологии
   - Агент базы знаний (Wiki)
   - Агент контроля поручений
```
