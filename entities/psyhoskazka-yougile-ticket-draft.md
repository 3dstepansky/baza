## Заголовок

ПсихоСказка: проверить пол в промпте и добавить «печатает…» при генерации

## Описание

Нужно выкатить новую версию Telegram-бота ПсихоСказка / LusherTale с двумя улучшениями:

1. **Проверить промпт на соответствие по полу**
   - Убедиться, что обращения и формулировки в генерируемом тексте соответствуют полу пользователя.
   - Проверить системный/пользовательский prompt и места, где в него подставляются данные пользователя.
   - Если пол неизвестен — использовать нейтральные формулировки, не ломать UX.

2. **Добавить “печатает…” во время генерации**
   - Пока бот ждёт ответ от AI/генератора сказки, отправлять Telegram typing action (`sendChatAction` / `ChatAction.TYPING`).
   - Для длинной генерации повторять typing action с интервалом, чтобы статус не исчезал.
   - Не оставлять вечный background task после завершения/ошибки генерации.

## Acceptance criteria

- [ ] Пользователь видит «печатает…» во время генерации сказки/ответа.
- [ ] После успешной генерации typing loop корректно останавливается.
- [ ] После ошибки генерации typing loop тоже корректно останавливается.
- [ ] Промпт не использует мужской/женский род неправильно при известном поле пользователя.
- [ ] При неизвестном поле используются нейтральные формулировки.
- [ ] Изменения запушены в GitHub отдельной веткой/коммитом.
- [ ] Приложена ссылка на GitHub ветку/коммит/PR.
