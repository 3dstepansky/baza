Academic Difference Assistant — ассистент расчёта академической разницы

Суть: проект ассистента для автоматизации расчёта академической разницы по академическим справкам, дипломам и учебным планам. MVP обсуждается как Telegram-бот с промежуточным human-in-the-loop подтверждением спорных сопоставлений дисциплин. ^[raw/transcripts/academic-difference-assistant-meeting-2026-08-03-transcript.md]

Контекст встречи

Участники обсуждали расчёт академической разницы для факультета техносферной безопасности. Ключевой затык был в недостатке размеченных примеров; после получения двух Excel с цветной разметкой областей методика стала понятнее для нейросетевого расчёта. ^[raw/transcripts/academic-difference-assistant-meeting-2026-08-03-transcript.md]

MVP-форма результата

Ожидаемый результат на первом этапе:

  • Excel-таблица с расчётом: дисциплины, семестр, АР/AR, срок доучивания;
  • текстовое сообщение/письмо с кратким результатом;
  • промежуточное согласование спорных мест в Telegram-боте до формирования финального файла.

Важная UX-идея: бот не должен просто выдавать готовый Excel, который оператор потом полностью перепроверяет. Он должен по ходу расчёта подсвечивать спорные сопоставления — например, «русский язык и информатика русского языка» — и просить оператора подтвердить направление решения. ^[raw/transcripts/academic-difference-assistant-meeting-2026-08-03-transcript.md]

Архитектурные решения

  • Telegram-бот — интерфейс для загрузки материалов, уточняющих вопросов и подтверждения расчёта.
  • Локальная нейросеть / локальный сервер — предпочтительный production-вариант для конфиденциальности и 152-ФЗ.
  • Альтернатива: предварительная обезличивающая модель, которая удаляет ФИО и оставляет только данные, необходимые для расчёта.
  • MVP без 1С: на первом этапе можно работать без прямой интеграции с 1С; данные выгружаются/загружаются вручную, результат затем переносится в нужные поля.

Проблемные места

  1. OCR/качество справок: реальные фотографии справок могут быть пиксельными и плохо читаемыми; классическое OCR уже показало провалы.
  2. Семантическое сопоставление дисциплин: ценность человека-оператора сохраняется на пограничных случаях.
  3. Конфиденциальность: production-контур должен минимизировать передачу персональных данных во внешние сервисы.
  4. Фейковые справки: после MVP можно добавить attention-модуль для подозрительных паттернов: слишком высокий процент совпадения с учебным планом, странные часы, организация создана позже даты справки, отсутствие нормальной шапки/печати.

Следующие шаги

  • Создать Telegram-бота для MVP.
  • Дособрать правила расчёта и словарь сопоставлений дисциплин.
  • Использовать два новых размеченных Excel как ключевые обучающие/методические примеры.
  • Обсудить с Антоном/ИТ production-архитектуру и требования по персональным данным.
  • Проверить MVP к контрольной точке «пятница этой недели».
