# Green Broker — экосистема и боты для питомников растений

## Суть

**Green Broker** — экосистема автоматизации продаж, складского учета и брокериджа на рынке посадочного материала (питомники растений, садовые центры, ландшафтные дизайнеры и оптовые закупщики). ^[raw/articles/green-broker-constitution-2026-08-02.md] ^[raw/transcripts/telegram-green-broker-two-bot-architecture-and-brokerage-2026-09-08.md]

Проект строится по модели **SaaS-enabled Marketplace**:
1. Для питомников — это удобный инструмент (SaaS) для ведения склада и автоматический 24/7 AI-отдел продаж по их собственным клиентам.
2. Для платформы Green Broker — это агрегация актуальных остатков сотен питомников в реальном времени и возможность продавать их ассортимент через собственные каналы брокериджа.

В результате проработки концепции с Романом сформирована целевая двухботовая архитектура с разделением контуров поставщика (питомника) и покупателя (клиента). ^[raw/transcripts/telegram-green-broker-two-bot-architecture-and-brokerage-2026-09-08.md]

 │                   Green Broker Core                    │
 │         (База остатков, брокерский маркетплейс)        │
 └───────────────────────────┬────────────────────────────┘
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
┌─────────────────────────┐       ┌─────────────────────────┐
│  Green Broker Питомник  │       │   Green Broker Client   │
│   (Vendor / Warehouse)  │       │  (AI-Sales & Retention) │

   2. Загрузка прайсов/фото    ───────────►   │ 3. Генерация КП

            │                                 │

### 1. Бот «Green Broker Питомник» (Поставщик / Склад)
*Интерфейс для владельцев, агрономов и управляющих питомников.*

- **Складской учет без тяжелых ERP:** ввод, корректировка и синхронизация актуальных остатков саженцев, кондиций (высота, ком/контейнер), сортов и цен.
- **Быстрый онбординг прайс-листов:** загрузка Excel/PDF/фото для автоматического распознавания и обновления номенклатуры.
- **Генератор точек входа (Deep Links):** выдает персональную ссылку на клиентского бота (например, `t.me/GreenBrokerClientBot?start=nursery_1`).
- **Оперативный дашборд:** уведомления о сформированных КП, бронях и запросах от клиентов.

### 2. Бот «Green Broker Client» (Клиент / Переговорный AI-агент)
*«Переговорный ChatGPT» для существующих и входящих клиентов питомника.*

- **Контекстная изоляция:** при переходе по ссылке конкретного питомника (например, Питомника №1) бот консультирует строго по ассортименту и ценам этого питомника.
- **Умная консультация и подбор:** понимает неструктурированные запросы («нужна живая изгородь из туй 1.8м на 50 метров»), проверяет наличие на складе питомника и предлагает точные позиции или аналоги.
- **Мгновенный расчет и КП:** генерирует и отправляет клиенту оформленное коммерческое предложение (PDF/сообщение) с ценами, характеристиками и условиями доставки.
- **Проактивный Retention / Follow-up («догонять, бегать, спрашивать»):**
  - Автоматически возвращается к клиенту спустя заданное время («Удалось посмотреть КП? Нужна ли помощь с посадкой/доставкой?»).
  - Напоминает о сезонных работах, допродажах (удобрения, сопутствующие растения, мульча).
  - Стимулирует повторные заказы существующих клиентов.
- **Омниканальность:** питомник может ставить ссылку на этого Telegram-бота на свой сайт, в соцсети, карты (Яндекс/2ГИС), на рекламные баннеры и визитки.

### 3. Брокерский контур: продажи через каналы Green Broker
- Green Broker не ограничивается обслуживанием внутренних клиентов конкретного питомника.
- Имея прямую интеграцию со складами множества питомников, **Green Broker сам выступает оптовым брокером/селлером**:
  - Продает объемы питомников через собственные каналы сбыта (крупные девелоперы, городское благоустройство, федеральные ландшафтные бюро, B2B-закупки).
  - Закрывает сложные сборные спецификации (когда ни один отдельный питомник не имеет 100% позиций в наличии).

## Сравнение контуров системы

| Параметр | Green Broker Питомник | Green Broker Client | Green Broker Брокеридж |
| :--- | :--- | :--- | :--- |
| **Пользователь** | Сотрудник/владелец питомника | Покупатель (дизайнер, оптовик, частник) | B2B-байер / Девелопер / Платформа |
| **Роль LLM** | Распознавание прайсов, структурирование остатков | Переговорщик, консультант, продавец, retention | Оптимизация сборных заказов, кросс-матчинг |
| **Ключевой триггер** | Изменение остатков, отгрузка | Входящий запрос, клик по ссылке, таймер follow-up | Внешняя оптовая заявка / тендер |
| **Главный результат** | Актуальная база остатков | Сформированное КП + закрытая сделка | Комиссионная продажа для Green Broker |

## Модель монетизации и ценности

1. **Для питомника:**
   - Экономия на ФОТ менеджеров по продажам и складских операторов.
   - 0 потерянных лидов в нерабочее время и в сезонный пик.
   - Увеличение LTV за счет автоматических повторных продаж и дожимов.
   - Дополнительная выручка от брокерских продаж самого Green Broker.
2. **Для платформы Green Broker:**
   - Подписочная модель (SaaS) за функционал ботов и складского учета.
   - Комиссия (транзакционная модель / маржа брокера) за продажи через собственные каналы.

## Риски и фокусы разработки

- **Синхронизация остатков:** предотвращение продажи одной и той же позиции одновременно через клиентского бота и оффлайн-склад (резервирование).
- **Промпт-инжиниринг переговорщика:** удержание рамок конкретного питомника в `Green Broker Client`, корректный тон общения, ненавязчивый, но эффективный follow-up.
- **Генерация КП:** скорость формирования аккуратного PDF/визуального предложения с фото и характеристиками растений.
