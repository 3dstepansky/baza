Российские grocery-приложения и MCP-серверы — план исследования

Павла интересуют именно MCP-серверы и возможность сделать MCP-интеграции для российских приложений доставки/ритейла, альтернативных Яндекс Лавке.

Целевые приложения

Приложение / сеть Приоритет Что проверить
Самокат высокий наличие публичного/неофициального API, веб-каталог, гео, корзина, антибот
Пятёрочка высокий X5/5ka API, цены, акции, наличие, доставка/самовывоз, авторизация
Перекрёсток высокий X5 API, каталог, корзина, привязка к адресу/магазину
Лента средний каталог, доставка, гео, web/mobile endpoints
Магнит средний каталог, акции, наличие, доставка/магазины
Красное и Белое средний каталог, магазины, наличие; учитывать ограничения по алкоголю
Евроспар средний каталог, доставка, наличие, региональность

Что искать

  1. Готовые MCP-серверы на GitHub и в каталогах MCP.
  2. Не-MCP библиотеки/API-клиенты для этих сервисов, которые можно обернуть в MCP.
  3. Веб/mobile endpoints: каталог, поиск, карточка товара, наличие, цены, акции.
  4. Авторизация: cookies, session, phone OTP, captcha/anti-bot.
  5. Возможность безопасных tools:
  6. search_products
  7. get_product_card
  8. get_availability
  9. get_promos
  10. get_cart
  11. add_to_cart
  12. checkout_preview
  13. Жёсткое правило безопасности: реальный заказ/оплата — только после явного подтверждения пользователя.

Предварительный вывод

На момент первичного поиска готового публичного MCP именно под российские grocery-приложения не найдено. Вероятный путь — сделать собственные MCP-адаптеры поверх веб/mobile API, начиная с наиболее доступного сервиса.

Критерии выбора первого сервиса

Критерий Почему важно
Каталог доступен без сложной авторизации можно быстро сделать поиск и сравнение цен
Есть web endpoints, а не только мобильное API проще автоматизация и отладка
Гео/магазин задаётся прозрачно цены и наличие зависят от адреса
Корзина отделена от оплаты безопасно автоматизировать до checkout-preview
Антибот умеренный меньше поддержки и падений

Следующий практический шаг

Провести технический разведочный проход по каждому сервису: GitHub search → web endpoints → network/API inspection → минимальный probe без заказа. Итогом должна быть таблица: готовый MCP / есть библиотека / API доступен / сложность / рекомендуемый первый кандидат.
