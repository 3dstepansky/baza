# Spec Kitty — source snapshot

Репозиторий из семейства spec-driven workflow. Нужен как практический пример: превращать намерение пользователя в набор specs/tasks, которые можно выдавать агентам как независимые work packages.

Полезный паттерн: agent-friendly спецификации должны быть маленькими, тестируемыми и иметь Definition of Done.
