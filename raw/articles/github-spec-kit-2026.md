# GitHub Spec Kit — source snapshot

Источник для spec-driven разработки с агентами. Центральная идея: сначала спецификация и план, затем задачи и реализация. Это снижает хаотичный вайбкодинг и делает работу агентов проверяемой.

Для automation-проектов это особенно важно: workflow, интеграции, права доступа, данные, побочные эффекты и критерии приёмки должны быть описаны до запуска кодирующих агентов.
