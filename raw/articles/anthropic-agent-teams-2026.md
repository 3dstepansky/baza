# Claude Code Agent Teams — source snapshot

Исходник для исследования методологии многоагентной разработки. Зафиксированы идеи: явные роли агентов, разделение контекста, делегирование специализированным subagents, управление permissions/tools и необходимость проверяемых критериев результата.

Ключевая ценность для проекта: Claude Code agent teams рассматриваются не как «магия», а как инженерная организация труда: orchestrator распределяет задачи, specialist agents работают в изолированных контекстах, reviewer/QA проверяет артефакты, человек принимает решения на границах риска.
