# Multi-agent software engineering — paper snapshot

Академический источник по многоагентной разработке ПО. Используется для отделения инженерных паттернов от хайпа: координация, коммуникация, память, разбиение задач, оценка качества и воспроизводимость.

Ключевой вопрос для дальнейшего синтеза: где много агентов реально повышают качество, а где только расходуют токены и создают рассинхрон.
