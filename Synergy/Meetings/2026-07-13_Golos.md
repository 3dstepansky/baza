# Встреча 13.07.2026 — Настройка Hermes в топиках Telegram

**Источник:** расшифровка голосового сообщения
**Участники:** Спикер 1, Спикер 2

## Основные темы

### 1. Топики Telegram для КПН
- Предложение: создать отдельный топик для КПН в общем чате
- Туда сваливается вся информация по КПН: протоколы, регламенты, файлы
- Протоколы приходят от Елены → форвард в топик КПН

### 2. Hermes Agent в топиках
- Гермес должен дообучиться ориентироваться в топиках
- При поступлении нового протокола — сравнивать с PostgreSQL/SQL на предмет дубликатов
- Писать сводку по КПН прямо в топик
- Проблема: Hermes сейчас выводит технические сообщения (какие скиллы запускает)
- Нужно: настроить ответы на русском, убрать тех. мусор

### 3. Kanban-доска и оркестратор (перспектива)
- **1-й слой:** Агент Gateway — слушает все топики Telegram → кладёт события в Kanban-доску
- **2-й слой:** Оркестратор — смотрит что пришло, роутит по типу сообщения
- **3-й слой:** ~15 специализированных агентов
  - Агент регламентов КПН
  - Агент терминологии
  - Агент базы знаний (Wiki)
  - Агент контроля поручений
  - и т.д.

### 4. Инфраструктура
- Дев-сервер (Павел) — инновации, тесты
- Прод-сервер (Медведев) — стабильная версия
- Настройки Hermes (.hermes/) — копировать на сервер для полного клона
- Пайплайн релизов после отладки

### 5. Первые шаги (на сегодня/завтра)
1. Настроить Gateway — слушать топик КПН
2. При пересылке таблички/регламента в чат — Гермес переваривает
3. Дайджест раз в день в топик: список поручений
4. Контроль статуса: «доклад на КПН такой-то готов?»
5. Дедупликация: если протокол уже есть — не дублировать
