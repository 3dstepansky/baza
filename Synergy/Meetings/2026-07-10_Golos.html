Встреча 10.07.2026 — Общий статус проекта КПН

Источник: расшифровка голосового сообщения Участники: Спикер 1, Спикер 2, Спикер 3, Спикер 4 (до 5 спикеров)

Основные темы

1. Статус LLM Wiki и реестра поручений

  • Получены стенограммы от Милены
  • Описан скрипт, который вытягивает стенограммы и обогащает их контекстом
  • Создан реестр поручений, где всё хранится
  • Используется LLM Wiki (Obsidian vault + Ollama)

2. Архитектура RAG

  • LLM Wiki — человекочитаемое общение, ответы на вопросы
  • GraphRAG — глубокие ответы, поиск релевантных сегментов в стенограммах
  • Ollama 3.2 (8B/3B?) — локальный контур, медленный, но работает
  • Рассматривается Claude как замена для скорости

3. Контроль поручений (приоритет)

  • Реестр поручений из стенограмм → YouGile интеграция
  • Telegram-бот для напоминаний ответственным
  • Уведомления за неделю/срок до дедлайна
  • Вариант с дашбордом для статусов

4. Интеграции

  • YouGile — техническое подключение есть, нужен доступ к аккаунту Jira/YouGile
  • Telegram — бот должен писать в чаты, отмечать ответственных
  • Почта — коннектор для email как источник данных
  • Комментарии к сообщениям как механика обратной связи

5. Конфликт приоритетов

  • Спикер 1 настаивает: брать всё и сразу ≠ ничего не будет
  • Нужно начать с одного сценария (понедельник — планерка, дашборд ДТП)
  • MVP: заменить человека на напоминалках и дашборде

6. Архитектура LLM

  • Ollama 3.2 (локально) — упирается в контекст
  • Предложение: поднять свой LLM Hub или использовать внешние API
  • Security concerns при внешних моделях
  • Claude — перспективная замена, протестировать
